# American BBQ: Smoked Shredded Chicken Thighs

Full recipe in `recipe.json` (schema.org/Recipe). Ingredients are grouped into components (Rub / Cooking / To serve) using "## Component" header rows.

Original cook: 110°C throughout, about 3-3.5 hours. This version raises the heat to 150°C after wrapping to aim for about 2.5 hours total; that faster version is untested, so `cookTime` is set to the original 3.5 hours.

The rub is half the Memphis pulled pork rub from the BBQ School book (see `memphis-pulled-pork/`). The yield is by weight; no serving count was given.
